**Key Technical Concepts**
- **Carregamento Sob Demanda (On-Demand Loading):** A página de Downloads foi refatorada para carregar uma quantidade mínima de dados inicialmente e buscar o restante apenas sob interação do usuário. Este padrão é crucial para a performance da aplicação.
- **Estado Global via WebSocket:** O backend agora envia ativamente estatísticas de jobs (, ) via WebSocket. O objetivo é usar esses eventos para acionar ações globais na UI (como notificações sonoras) de forma eficiente.
- **Fallback de Dependência:** O worker de OCR implementa uma estratégia de fallback: tenta usar a biblioteca  para detecção de mimetype e, em caso de falha (ex:  não instalado), recorre à biblioteca nativa  do Python para evitar que a aplicação quebre.
- **Cancelamento de Efeitos em React:** Foi implementado um padrão com um  () para verificar se um componente ainda está montado antes de atualizar seu estado dentro de  com dependências assíncronas. Isso previne erros e memory leaks durante a navegação rápida entre páginas que fazem polling.
